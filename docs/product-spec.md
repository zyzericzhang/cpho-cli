# CPHO CLI — 产品说明

## 它是什么

CPHO CLI 是一个**本地命令行工具**。用户在终端输入一行命令，指向自己文件夹里的题目（PDF 或扫描图片），
工具经过 OCR 文本提取和多步骤 AI 解析后，输出结构化的物理推导和分析结果。

它不是一个在线服务。不需要注册账号，不需要上传文件，不需要等待后端部署。
除了调用 LLM API 之外，所有计算在用户自己的机器上完成。

## 它解决什么问题

当前 CPHO AI Platform 的 AI Solver 已经能对上传的题目进行 7 段式解析，但调试解析质量的过程很痛苦：

- 改 prompt → 要在代码里改，提交，部署，等上线
- 对比效果 → 要手动截屏、粘贴、肉眼 diff
- 跑批量测试 → 要一张张上传 PDF，没法对文件夹一键操作
- 调参数 → 模型、temperature、分步策略……每次改动都涉及前端 UI 和后端逻辑

CLI 把所有这些摩擦全部消除。它不做任何线上平台做的事，只做一件事：**让你用最快的速度迭代解析质量**。

## 典型用户和场景

### 用户 A：物理竞赛教练

手头有过去 5 年复赛、决赛的全部真题 PDF，文件夹里几百道。
他想：把这些题全部跑一遍 AI 解析，看看质量怎么样。质量不好的题，调一调 prompt 或者换模型重新跑。

他做的事：
```bash
# 1. 先拿一道题试试
cpho solve "2024-复赛-力学题.pdf" --answer "答案.pdf"

# 2. 调参数
cpho solve "2024-复赛-力学题.pdf" --answer "答案.pdf" \
  --prompt derivation-v2.md --model gemini-2.5-pro

# 3. 确认效果后，批量跑
cpho batch ./all-problems/ --answer-dir ./all-answers/ --output ./results/
```

### 用户 B：平台开发者（你）

你在为线上平台迭代解析策略。在 CLI 里调好 prompt 和参数组合，确认质量 OK 后，
把同样的 prompt 模板同步到线上平台的 `docs/ai-prompts/` 目录。

### 用户 C：愿意折腾的学生

有十几道自己收集的题，想看看 AI 怎么推导。不在乎命令行难不难看，
只在乎推导过程有没有跳步，物理定律用没用对。

## 和线上平台的关系

```
CPHO CLI（本地）                  CPHO AI Platform（线上）
─────────────────                  ─────────────────────
本地 PDF/图片文件夹                Supabase 存储
用户自己的题库                     Problem Bank 公共题库
命令行操作                         Web UI 操作
本地跑，结果存本地                 在线跑，结果存数据库
参数面板 = YAML 配置文件            参数 = 后台系统配置

共享层：
  prompt 模板（Markdown 文件）
  解析策略（Planner-Worker 拆分逻辑）
  输出 JSON Schema
  评测标准（Golden Dataset + Rubric）
```

CLI 不是线上平台的替代品，也不是它的命令行版本。它们是**同一个领域知识的两种交付方式**。

未来联动方向（v2+）：CLI 调好的配置可以同步到线上；线上跑的结果可以拉到本地对比。

## v1 范围

### 要做

- 读取一个文件夹，遍历其中所有 PDF 和图片
- OCR 提取文本（支持中英文混合的扫描版试卷）
- 多步骤 AI 解析（至少支持当前线上版 7 段输出结构的子集）
- 通过配置文件调整 prompt 模板和模型选择
- 结果输出为 JSON 文件
- `pip install` 即可使用

### 明确不做

- GUI / TUI / Web 界面
- 自动评分（用户自己看结果判断）
- 数据库存储（文件系统 + JSONL 足够）
- 多用户 / 权限 / 登录
- 和线上平台的数据同步（v2+）
- 向量检索 / RAG（v2+）

## 核心假设（待验证）

1. **参数可控 → 质量更好**：把 prompt、模型、任务拆解策略暴露为可调参数，能让解析质量有显著提升空间
2. **本地文件夹 = 即用题库**：不需要任何导入流程，文件夹里的 PDF 直接能跑，是教练群体真正的需求
3. **CLI 先行的策略正确**：先服务愿意折腾的重度用户，快速迭代解析质量，比一开始就做易用性更高效

## 成功标准

1. 一个物理竞赛教练能在 5 分钟内：安装 → 指向自己的题目文件夹 → 跑出第一道题的解析结果
2. 改一个参数 → 重新跑 → 对比新旧结果，这个循环不超过 2 分钟
3. 至少有一个真实教练说"这东西比我手动整理好用"
