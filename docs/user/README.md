# 用户文档

按 skill 分章：

- [solve](solve.md) — 审查标准答案并记录 discrepancy。
- [explain](explain.md) — 多 Tone 讲解、句子级解释和候选标签回写。
- [probe](probe.md) — 连续主动提问关键物理点。
- [related](related.md) — 查找同类题。
- [compose](compose.md) — 用 YAML 编排文件生成题目卷和答案卷。
- [index](index.md) — 建立和维护本地题目索引。
- [knowledge](knowledge.md) — 标准化、发布和查找本地私有知识文件。
- [model-panel](model-panel.md) — 查看 skill pipeline 并设置每步模型。
