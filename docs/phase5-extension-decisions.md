# Phase 5 Extension Decisions

The extension guide documents the Python path that the codebase actually supports today: write a small core service and register a REPL command explicitly. It does not claim automatic arbitrary `builtin_skills/` scanning, because that mechanism is not implemented.

Examples are Markdown placeholders rather than public IPhO PNG assets. This avoids shipping third-party contest material before source/license verification. README tells users to replace `examples/` with their own workspace.
