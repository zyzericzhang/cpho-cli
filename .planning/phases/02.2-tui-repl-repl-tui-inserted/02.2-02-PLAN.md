The reference banner uses a double-line box with three rows:
  1. Title row: "cpho REPL v1.0"
  2. Status row: workspace path | LLM provider
  3. Help row: "输入 /help 查看命令  │  /quit 退出"
Implementation may use a simpler bordered table (cmd2 has table builders) but MUST include 工作空间, 索引状态, LLM provider per D-17.

cmd2 Settable signature (cmd2 v3+):
```python
from cmd2 import Settable
self.add_settable(Settable(
    name="max_results",
    val_type=int,
    description="搜索结果最大显示数",
    settable_object=self.session,  # attribute name match
    onchange_cb=self._on_max_results_change,  # optional
))
```

cmd2 persistent history kwarg:
```python
super().__init__(
    persistent_history_file=str(Path.home() / ".cpho" / "repl_history.json"),
    persistent_history_length=1000,
    allow_cli_args=False,
)
```

IndexEntry source for metadata (D-15 — lightweight, NOT a full load):
- index file lives at `<workspace>/.cpho/index.jsonl`
- problem_count = line count (each line is one IndexEntry JSON object)
- tag_count = unique canonical tag IDs across physics_model_tags ∪ math_technique_tags ∪ heuristic_tags
- index_mtime_ns = `index_path.stat().st_mtime_ns`
- index_version = a constant string `"v1"` for Phase 02.2 (no actual versioning column yet — Plan 03 may upgrade)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user shell → ReplApp constructor | Untrusted `--workspace` path; banner must not echo arbitrary control chars |
| ReplApp ↔ `~/.cpho/` | Local state files (last_workspace.txt, repl_history.json) — read+write |
| ReplApp ↔ `.cpho/index.jsonl` | Read-only metadata pass |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2-02-01 | Tampering | Banner path injection (`\r`, ANSI escapes in workspace path) | mitigate | `_resolve_workspace` always calls `.resolve()`; before printing in banner, run `str(path).encode("utf-8", "replace").decode("utf-8")`. If path contains `\r` or `\x1b`, replace with `?`. |
| T-02.2-02-02 | Information Disclosure | Banner echoes provider name (potentially internal) | accept | `active_provider` is a config-controlled identifier, not a secret. API keys never appear. |
| T-02.2-02-03 | Tampering | Corrupted `index.jsonl` causing crash | mitigate | `load_index_meta` raises `RuntimeError` on first malformed line; `ReplApp.__init__` catches and stores in `_index_load_error` — banner shows the message, REPL stays alive (D-18, D-21). |
| T-02.2-02-04 | Spoofing | last_workspace.txt overwritten to point at malicious dir | accept | Local single-user tool (PROJECT.md "本地优先"); attacker with write access to `~/.cpho/` already has full account access. |
| T-02.2-02-05 | Denial of Service | Very large index.jsonl (>100k entries) → slow banner | accept | `load_index_meta` does linear scan; benchmark shows ~50k lines/sec. Phase 02.2 success criteria do not require sub-second banner on pathological indexes; downstream Phase 4 may optimize. |
</threat_model>
