<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → process | Workspace YAML vocabulary files and .cpho/index.jsonl are read as untrusted YAML/JSON; malformed input must not crash silently. |
| process → filesystem | write_index writes under workspace_root/.cpho/; path must stay contained inside workspace_root (no traversal). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | .cpho/index.jsonl partial write on crash | mitigate | Atomic .tmp + Path.replace per AP-4; unit test asserts tmp file removed after success. |
| T-02-01b | Information Disclosure | private.yml committed accidentally | mitigate | private.yml lives under .cpho/ which is already gitignored; no new gitignore changes required. Document the path in vocabulary.py docstring. |
| T-02-01c | Denial of Service | Pathological vocab YAML (huge nested dict) crashes loader | accept | Local CLI, single user — Pydantic validation surfaces clear error; no remote attacker. |
| T-02-01d | DoS — schema drift | Phase 3 adds unknown field to YAML, StrictModel rejects | accept | This is the intended behavior of `extra="forbid"`. Phase 3 must extend the schema explicitly. |
</threat_model>
