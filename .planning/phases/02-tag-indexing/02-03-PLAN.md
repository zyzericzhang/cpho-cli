<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → process | Cache files in .cpho/cache/ocr/ are read on each cache hit; an attacker who can write to .cpho/ could plant a malicious OCRResult JSON. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | Adversary edits .cpho/cache/ocr/*.json to inject text that later flows into the LLM tagging prompt (prompt-injection vector) | accept | Local single-user CLI; .cpho/ lives inside the user's workspace and is under their full control. Document in code comments that cache contents are treated as recoverable, not authoritative — `--force` regenerates. |
| T-02-03b | DoS | Pathological OCRResult JSON (huge text field) | accept | Pydantic validation surfaces clear error; bounded by source PDF size. |
| T-02-03c | Information Disclosure | Cache files contain OCR text from problem PDFs | accept | .cpho/ is gitignored; user controls the directory. |
</threat_model>

Define `def detect_ocr_engine_upgrade(workspace_root: Path, current_engine: str, current_version: str, current_config_hash: str) -> OcrEngineDelta | None`:
- Try `entries = load_index(workspace_root)`; catch `IndexNotFoundError` and return `None` (no existing index, no upgrade to detect).
- If `not entries`: return None.
- Iterate entries; collect `(problem_id, e.fingerprint.semantic.ocr_engine, e.fingerprint.semantic.ocr_engine_version, e.fingerprint.semantic.ocr_config_hash)` tuples.
- An entry is "affected" iff any of its three OCR-related fingerprint fields differs from current.
- If `affected = []`: return None.
- Else: determine `old_engine, old_version, old_config_hash` from the most common stored tuple (use `Counter` from collections; pick the most_common one). Return `OcrEngineDelta(old_engine=..., old_version=..., old_config_hash=..., new_engine=current_engine, new_version=current_version, new_config_hash=current_config_hash, affected_count=len(affected), affected_problem_ids=[pid for pid, ... in affected])`.

Note about strategy values: `--ocr-strategy` (prompt|reuse|rebuild|new-only) is a CLI-layer concept. This module does NOT consume strategy strings; it ONLY detects and reports. Plan 02-05 builder calls `detect_ocr_engine_upgrade` and dispatches based on user-chosen strategy.
