<threat_model>
ASVS level: 1
Block on severity: high

Threats:
- HIGH: API key could be logged in request traces or exception text.
- HIGH: Model output could be treated as valid physics derivation without schema validation or answer-key grounding.
- MEDIUM: OpenRouter model/provider may not support requested structured output parameters.
- MEDIUM: Final report could hide OCR uncertainty.

Required mitigations:
- Redact `Authorization` headers and API keys from all provider errors and trace records.
- Use Pydantic validation for all structured LLM outputs.
- If structured output is unsupported, fail with a visible provider capability error unless the step explicitly allows JSON repair.
- Include OCR low-confidence blocks and answer discrepancies in final report fields.
</threat_model>
