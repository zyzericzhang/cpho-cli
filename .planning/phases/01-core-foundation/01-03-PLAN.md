<threat_model>
ASVS level: 1
Block on severity: high

Threats:
- HIGH: User-editable YAML skill metadata can trigger unsafe YAML construction or path traversal for templates.
- HIGH: Trace records can leak API keys, local secrets, or unexpectedly large problem content.
- MEDIUM: DAG cycles or missing blackboard keys can produce partial outputs that look valid.

Required mitigations:
- Use `yaml.safe_load()` and Pydantic `extra="forbid"` models for skill metadata.
- Restrict prompt template paths to the skill directory.
- Redact configured secret values before trace write.
- Fail fast on duplicate output keys, missing input keys, and DAG cycles.
</threat_model>
