## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| problem/answer files -> LLM prompts | Local physics files and OCR text are sent to the configured provider. |
| LLM output -> SolveReport | Provider JSON is validated into strict Pydantic models before use. |
| Solve findings -> index | Optional CLI/REPL persistence writes through the existing user_tags API only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering | `SolveReport.discrepancies` | mitigate | Keep discrepancies free text in report/session; optional index writes use `add_problem_tags` and preserve machine buckets. |
| T-03-03-02 | Information Disclosure | provider errors/traces | mitigate | Continue using existing `redact_secrets` and avoid adding API keys to markdown reports. |
| T-03-03-03 | Spoofing | official-answer review prompts | mitigate | Prompts must cite official-answer references for findings and not present a new solution as authoritative output. |
| T-03-03-04 | Repudiation | CLI confirmation and persistence | mitigate | Confirmation choices determine accepted findings; persisted entries include `skill_name="solve"` and reasoning/provenance snippets. |
</threat_model>
