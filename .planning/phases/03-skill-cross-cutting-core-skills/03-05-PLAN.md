<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM stream -> terminal markdown | Streaming chunks are rendered as markdown text per tone. |
| tone selection -> concurrent runtime calls | User-selected tones control the number of provider calls. |
| candidate tags -> index confirmation | LLM-derived tags are candidates until CLI/REPL confirmation in Plan 03-07. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | streamed prose rendering | mitigate | Keep per-tone chunk buffers separate and merge only after tone completion. |
| T-03-05-02 | Denial of Service | tone fan-out | mitigate | Fan-out count equals explicit selected tones; no recursive or DAG-level fan-out is added. |
| T-03-05-03 | Information Disclosure | Explain markdown | accept | User-requested skill output contains problem/answer context; service code excludes provider secrets. |
</threat_model>
