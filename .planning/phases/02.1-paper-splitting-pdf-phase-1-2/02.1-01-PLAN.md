## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local OCR/fixture JSON to Pydantic models | User-controlled OCR-like JSON becomes persisted split/index inputs. |
| OCR text to regex splitter | OCR text can contain misleading marker-like strings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-01-01 | Tampering | `ProblemEntry.problem_page_range` | mitigate | Validate 1-indexed inclusive ranges in `ProblemEntry` before any split result can persist. |
| T-02.1-01-02 | Spoofing | `problem_id` | mitigate | Generate ids from file SHA and problem number using `make_problem_id()`; tests assert determinism. |
| T-02.1-01-03 | Denial of Service | rule splitter | mitigate | Rule splitter uses one linear pass over OCR pages and anchored regexes only. |
| T-02.1-01-SC | Tampering | package installs | accept | No package-manager install occurs in this plan. |
</threat_model>
