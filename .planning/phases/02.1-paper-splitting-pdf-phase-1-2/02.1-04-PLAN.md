## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workspace files to OCR/split/tag pipeline | User-controlled local PDFs/images are loaded, OCRed, split, and optionally sent to an LLM. |
| configured provider credentials to LLM client | Local config/env secrets are used to construct an external provider client. |
| stale JSONL to new index output | Old persisted rows can otherwise survive into a rebuilt index. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-02.1-04-02 | Tampering | stale index reuse | mitigate | Use rebuild-safe loader and initialize result entries only from validated current-schema rows. |
| T-02.1-04-03 | Denial of Service | multi-problem indexing | mitigate | OCR each paper/answer once and split text into entries before per-problem tagging. |
| T-02.1-04-04 | Repudiation | split stats | mitigate | Persist split prompt version in fingerprints and expose split counters in CLI output. |
| T-02.1-04-SC | Tampering | package installs | accept | No package-manager install occurs in this plan. |
