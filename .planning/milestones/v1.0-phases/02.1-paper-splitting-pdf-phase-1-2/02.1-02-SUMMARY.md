## Decisions Made

- Used `split_prompt_version: v1` in the splitting prompt manifest to match the Phase 02.1 prompt-versioning constraint.
- Used a private `_LLMSplitResponse` schema so malformed provider output fails before any `ProblemEntry` or persistence path can consume it.
- Kept provider construction out of `split_paper()`; Plan 04 remains responsible for builder-level provider setup.
- Treated supported image suffixes as single-problem inputs before rules, and one-page no-marker inputs as single-problem after rule diagnostics.
