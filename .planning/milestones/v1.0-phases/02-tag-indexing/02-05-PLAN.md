`def query_index(workspace_root: Path, *, physics_model_ids: list[str] | None = None, math_technique_ids: list[str] | None = None, heuristic_ids: list[str] | None = None, match_mode: str = "any") -> list[IndexEntry]`:
- `entries = load_index(workspace_root)` (raises IndexNotFoundError if missing — propagate).
- Validate `match_mode in {"any", "all"}` else raise `ValueError(f"match_mode must be any or all, got {match_mode!r}")`.
- For each entry, build the entry's internal_id set per category: `pm_ids = {ref.internal_id for ref in entry.physics_model_tags}`, etc.
- For each provided filter list, check overlap:
  - "any" mode: entry matches a filter if `set(filter_ids) & entry_ids` is non-empty.
  - "all" mode: entry matches a filter if `set(filter_ids).issubset(entry_ids)`.
- Empty filters (None) are treated as "no constraint" (always match for that bucket).
- Across buckets: an entry is returned if it matches ALL provided (non-None) filters (intersection of constraints across categories) — this is the conjunction at the across-bucket level; "any"/"all" applies WITHIN each non-None filter list. Document this in the docstring with an example.
- Preserve input order (do not re-sort).

`def get_problem_entry(workspace_root: Path, problem_id: str) -> IndexEntry | None`:
- `entries = load_index(workspace_root)` (IndexNotFoundError propagates).
- For entry in entries: if entry.problem_id == problem_id: return entry. Return None if not found.

`def find_related_problems(workspace_root: Path, problem_id: str, *, min_shared_tags: int = 1, max_results: int = 10, same_category_weight: bool = True) -> list[tuple[IndexEntry, float]]`:
- Load all entries; locate the focal entry by problem_id; if not found, raise ProblemNotIndexedError(f"Not indexed: {problem_id}").
- For each other entry, compute overlap score:
  - Same-category overlap: `len(focal.physics_model_ids & other.physics_model_ids) + len(focal.math_technique_ids & other.math_technique_ids) + len(focal.heuristic_ids & other.heuristic_ids)` → each shared tag contributes 1.0.
  - Cross-category overlap (if same_category_weight is True): `len(focal_all_ids & other_all_ids) - same_category_count` → each cross-category shared tag contributes 0.5. (RESEARCH.md §7 specifies "相同 category 内重叠 +1, 跨 category +0.5".)
  - If same_category_weight is False, the cross-category bonus is 0; only same-category counts.
- Filter to `total_shared_canonical_tags >= min_shared_tags` (i.e., the integer count of shared canonical internal_ids, NOT the weighted score; threshold acts on raw overlap).
- Sort by score desc, take top `max_results`. Return list of (IndexEntry, float).

10. If `ocr_strategy == "reuse"`: skip upgrade detection (D-16 option c — preserve existing OCR even if engine differs); for stats, set `stats.ocr_engine_upgrade_detected = False`.
11. If `ocr_strategy == "rebuild"`: like "prompt" but force `force=True`-equivalent for affected entries (D-16 option b). For Phase 2 simplicity, implement this as: when constructing the per-problem action, if the problem's stored fingerprint has older OCR engine fingerprint than current, override action to `re_ocr_and_re_tag`. Set `stats.ocr_engine_upgrade_detected = True`.
12. If `ocr_strategy == "new-only"`: behave like only_new=True (D-16 option d — skip existing entries, only index new); set `stats.ocr_engine_upgrade_detected = True`.
13. `tag_prompt_version = load_tag_prompt_version()`. `params = resolve_model_params(config, "index")`.
14. `existing_entries: dict[str, IndexEntry] = {e.problem_id: e for e in load_index(workspace_root)} if (workspace_root / ".cpho" / "index.jsonl").exists() else {}`.
15. `inner_ocr = ocr_provider or RapidOCRProvider()`; `cached_ocr = CachedOCRProvider(inner_ocr, workspace_root / OCR_CACHE_DIRNAME, RAPIDOCR_ENGINE_NAME, ocr_engine_version)`.
16. `used_ids: set[str] = set()`.
17. `result_entries: list[IndexEntry] = list(existing_entries.values())`. We will mutate by problem_id.
18. `trace_path = workspace_root / ".cpho" / "run-trace.jsonl"`.

    - For the semantic fingerprint we need vocabulary.version, params (model_name + temperature), tag_prompt_version, TAG_SCHEMA_VERSION, ocr engine/version/config_hash:

    - `fingerprint = compose_index_fingerprint(file_fp, semantic_fp, user_learning_fp)`.
    - `old = existing_entries.get(problem_id)`.
    - `action = decide_action(old, fingerprint)`.
    - If `force` and old is not None: original_action_was_skip = (action == "skip"); action = "re_ocr_and_re_tag"; if original_action_was_skip: forced_override = True else: forced_override = False. (When `--force` flips a `skip` action into `re_ocr_and_re_tag`, the file content did NOT change — the user just asked us to re-run anyway. We must record this in `stats.forced_regenerations` instead of inflating `stats.file_changed`.)
    - If `force` and old is None: action = "full_index" (new problem; no override accounting needed); forced_override = False.
    - If not `force`: forced_override = False.
    - If `only_new` and old is not None: action = "skip"; forced_override = False (only_new takes precedence over force? — no: --force is explicit user intent and wins; in code, evaluate `force` after `only_new` so force still flips a skip. If both are set, force wins for this problem and the `only_new` flag is effectively ignored for this entry; document this in the function docstring.).
    - If `ocr_strategy == "rebuild"` and old is not None and old.fingerprint.semantic.ocr_engine_version != ocr_engine_version: action = "re_ocr_and_re_tag"; forced_override = False (OCR-engine-driven rebuild is a real semantic change, not a user --force; count via `stats.ocr_engine_upgrade_detected = True` already set above).
    - Dispatch:
      - "skip": `stats.tags_skipped += 1; stats.file_unchanged += 1` (if old.file == new) — keep old entry; continue.
      - "refinement_only": project notebook → IndexEntry user_confirmed_* fields. Build new entry by `entry = old.model_copy(update={"fingerprint": fingerprint, "user_confirmed_key_points": notebook.key_points if notebook else [], "user_confirmed_stuck_points": notebook.stuck_points if notebook else [], "indexed_at": datetime.now(timezone.utc)})`. `stats.refinement_only += 1`. Replace in result_entries.
      - "re_tag_only": reuse OCR cache. `document = load_document(problem_path)`; `ocr = cached_ocr.extract(document)` (cache should hit since file content unchanged); `report = _load_solve_report(workspace_root, problem_id)`; `solve_report_tags = _solve_report_tag_dict(report)`; `mapping = refine_tags(problem_id, _ocr_text(ocr), solve_report_tags, vocabulary, config, provider_config, llm_provider=llm_provider, trace_path=trace_path, source=TagSource.SOLVE_REPORT if report else TagSource.OCR_FALLBACK)`; assemble new IndexEntry; `stats.tags_regenerated += 1; stats.file_unchanged += 1; stats.ocr_reused += 1`. Append candidates to pending (T2-c below).
      - "re_ocr_and_re_tag": same as re_tag_only but cache miss expected. `re_ocr_and_re_tag` fires when the file fingerprint differs (decide_action) OR when `--force` / `ocr_strategy=="rebuild"` overrides a skip/refinement action. The OCR cache key embeds the file sha, so on a real content change the cache always misses. Stats accounting: if `forced_override is True` (the user passed `--force` and the underlying action would have been `skip` — content unchanged), increment `stats.forced_regenerations += 1` and DO NOT increment `stats.file_changed`; still increment `stats.ocr_regenerated += 1` and `stats.tags_regenerated += 1` (the LLM is re-run by user intent). If `forced_override is False` (the file fingerprint genuinely differs, or this is a new entry via the `full_index` path), increment `stats.file_changed += 1; stats.ocr_regenerated += 1; stats.tags_regenerated += 1`.
      - "full_index": new entry — same as re_ocr_and_re_tag but stats counters: `stats.file_changed += 1; stats.ocr_regenerated += 1; stats.tags_regenerated += 1`. (No `last_was_cached` branch — this path always represents a previously-unseen problem_id, so the OCR cache may or may not contain the file_sha; if `cached_ocr.last_was_cached` is True here, still increment `ocr_regenerated` because the entry itself is newly indexed; ocr_reused is reserved for the `re_tag_only` branch.)
      - For all branches that produce a new entry: build `IndexEntry(problem_id=problem_id, problem_path=problem_path.relative_to(workspace_root), answer_path=answer_path.relative_to(workspace_root) if answer_path else None, indexed_at=datetime.now(timezone.utc), physics_model_tags=mapping.physics_model_tags, math_technique_tags=mapping.math_technique_tags, heuristic_tags=mapping.heuristic_tags, difficulty_aspects=mapping.difficulty_aspects, user_confirmed_key_points=notebook.key_points if notebook else [], user_confirmed_stuck_points=notebook.stuck_points if notebook else [], fingerprint=fingerprint, solve_report_path=Path("output") / f"{problem_id}-report.json" if report else None, ocr_cache_path=None, ocr_text_length=len(_ocr_text(ocr)), tag_prompt_version=tag_prompt_version)`.
      - Replace by problem_id in result_entries.
20. After loop, write index: `write_index(workspace_root / ".cpho" / "index.jsonl", result_entries)`.
21. Append all collected candidates from this run to `.cpho/vocabulary/pending.yml` (merge with existing if file exists; dedupe by `normalize_alias(display_zh_suggestion)` and increment `occurrences`). `stats.candidate_tags_proposed = N` (count of NEW candidates emitted this run, not cumulative). `stats.pending_review_items = len(list_pending_candidates(workspace_root))` (cumulative after merge). Implement candidate merge as a helper `_merge_candidates(workspace_root, new_candidates)` inside builder.py that reads existing pending.yml (or empty list), groups by normalized display_zh, increments occurrences, and writes back atomically (.tmp + replace). Use yaml.safe_dump with allow_unicode=True for Chinese strings.
22. Return `stats`.

Exception flow: all `IndexBuildError` and subclasses propagate to caller (CLI will translate). `OcrUpgradeDecisionRequired` is raised in step 9 before any writes.
