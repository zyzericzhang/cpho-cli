### `src/cpho_cli/cli/repl/app.py` (entrypoint, prompt_toolkit 主循环)

**分析:** 现有 `cli/app.py` 是 **Typer** 的声明式入口（单次命令分发），与 REPL 的**持续 prompt 循环**形态差距很大。主循环模式**没有 in-repo 类比**，必须按 spike COMPARISON.md §7 草图实现。

**Imports 模式（对齐项目风格）—— 参考 `cli/app.py:1-16`：**
```python
# 既有约定：from __future__ import 省略（cli 层未用 future import；core 层全部 use）
# 标准库 → 第三方 → 项目内（按层）
from pathlib import Path
from typing import Optional

import typer

from cpho_cli.core.config import ConfigError
from cpho_cli.core.index import IndexNotFoundError, ...
```
→ **REPL app.py 沿用此分组**；新增 prompt_toolkit 段（第三方）：
```python
from prompt_toolkit import PromptSession
from prompt_toolkit.history import FileHistory
from prompt_toolkit.formatted_text import FormattedText
```

**主循环模式（直接从 spike COMPARISON.md §7 行 265-282 复制并扩展）：**
```python
async def repl_loop(session_state: SessionState) -> None:
    prompt_session = PromptSession(
        history=FileHistory(history_path),
        completer=CphoCompleter(registry),
        lexer=CphoLexer(),                     # D-12 输入行语法高亮
    )
    while True:
        try:
            line = await prompt_session.prompt_async("cpho> ")
        except (EOFError, KeyboardInterrupt):  # D-21: Ctrl+D 退出, Ctrl+C 继续
            break
        cmd_name, *args = shlex.split(line)
        cmd = registry.get(cmd_name)
        if cmd:
            await cmd.handler(session_state, args)
        else:
            print(f"未知命令: {cmd_name}，输入 /help 查看可用命令")
```

**错误处理模式 —— 参考 `cli/app.py:46-47, 78-79, 124-152`：**
```python
# 既有：捕获 ConfigError / SolveError / EvalConfigError，转成 typer.BadParameter
except (ConfigError, SolveError) as exc:
    raise typer.BadParameter(str(exc)) from exc
```
→ **REPL 必须分歧（D-21）：** REPL 不能 `raise` 退出，必须 **catch 全部 Exception 后调 `display.error(msg)` 并继续下一轮 prompt**：
```python
try:
    await cmd.handler(session_state, args)
except KeyboardInterrupt:
    display.warn("中断")          # D-21: Ctrl+C 不退出
except Exception as exc:
    display.error(str(exc))
    logger.exception("repl handler failed")  # 写 ~/.cache/cpho/repl.log
```

**Banner 模式 —— 参考 `cli/app.py:154-183` 的「索引统计」分隔线风格（`─────────────────────────`）：**
- 沿用 box-drawing 字符；非 UTF-8 终端 fallback 到 `+-|`（D-17 specific-idea）
- 字段顺序：workspace 路径 → index 状态（题数/标签数 或 "未建立"）→ LLM provider

**❌ 必须分歧的点：**
1. 现有 `cli/app.py` 是同步 Typer；REPL 是 **async**（`prompt_async`）。整个 `repl/app.py` 顶层是 `asyncio.run(repl_loop(...))`。
2. 异常**不向上 raise**（REPL 是长生命周期会话，与 Typer 单次命令相反）。

### `src/cpho_cli/cli/repl/completers.py` (`CphoCompleter(Completer)`, `CphoLexer(Lexer)`)

**Analog:** **No in-repo analog.** Completer / Lexer 是 prompt_toolkit 概念，本仓库不存在。

**Reference:**
- spike COMPARISON.md §3.3 表 + §4.4 `CphoLexer` 草图（行 172-178）
- prompt_toolkit 文档: https://python-prompt-toolkit.readthedocs.io/en/master/pages/reference.html#completer
- 参考实现：pgcli、IPython 的 Completer 子类

**Completer 骨架（必须新写，无 in-repo 模板）：**
```python
from prompt_toolkit.completion import Completer, Completion
from prompt_toolkit.document import Document

class CphoCompleter(Completer):
    """根据 registry + Command.completer 路由：
    - 输入行以 / 开头 → 命令名补全（registry.keys()）
    - 已识别命令 → 委派给 Command.completer
    """
    def __init__(self, registry: dict[str, Command], tag_cache: list[str]):
        self._registry = registry
        self._tag_cache = tag_cache  # D-14: 启动时一次性加载

    def get_completions(self, document: Document, complete_event):
        text = document.text_before_cursor
        if text.startswith("/") and " " not in text:
            for name, cmd in self._registry.items():
                if name.startswith(text):
                    yield Completion(name, start_position=-len(text), display_meta=cmd.help)
            return
        # 委派
        cmd_name, *_ = shlex.split(text)
        cmd = self._registry.get(cmd_name)
        if cmd and cmd.completer:
            yield from cmd.completer.get_completions(document, complete_event)
```

**CphoLexer（D-12 输入行高亮）—— 参考 spike §4.4：**
```python
from prompt_toolkit.lexers import Lexer
from prompt_toolkit.formatted_text import FormattedText

class CphoLexer(Lexer):
    def lex_document(self, document):
        def get_line(lineno):
            line = document.lines[lineno]
            tokens: list[tuple[str, str]] = []
            for token in line.split():
                if token.startswith("/"):
                    tokens.append(("class:cmd", token + " "))   # 蓝色
                elif token.startswith("--"):
                    tokens.append(("class:flag", token + " "))  # 黄色
                else:
                    tokens.append(("class:arg", token + " "))   # 绿色
            return tokens
        return get_line
```

**Style 注册（在 `app.py` PromptSession 构造时）：**

    "cmd": "#5f87ff",   # 蓝

    "arg": "#5fd75f",   # 绿
})

def write_index(path: Path, entries: list[IndexEntry]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)

**REPL persistence 套用（D-24 用 stdlib json）：**
```python
import json
import os
from pathlib import Path

def _config_dir() -> Path:
    base = os.environ.get("XDG_CONFIG_HOME") or str(Path.home() / ".config")
    p = Path(base) / "cpho"
    p.mkdir(parents=True, exist_ok=True)
    return p

def write_session(session: SessionState) -> None:
    path = _config_dir() / "session.json"
    tmp = path.with_suffix(".json.tmp")
    payload = {
        "workspace_path": str(session.workspace_path),
        "last_search_query": session.last_search_query,
        "last_search_result_ids": session.last_search_result_ids,
        "current_problem_id": session.current_problem_id,
        "index_mtime_ns": session.index_meta.index_mtime_ns if session.index_meta else None,
        "index_version": session.index_meta.index_version if session.index_meta else None,
    }
    tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")
    tmp.replace(path)

def read_session() -> dict | None:
    path = _config_dir() / "session.json"
    if not path.exists():
        return None
    return json.loads(path.read_text(encoding="utf-8"))
```

### `src/cpho_cli/cli/repl/commands/search.py` (`/search`, `/show` handler)

**Analog:** `src/cpho_cli/cli/app.py:207-253` — `topic_browse` / `compose_command` 直接调 core API 模式。**exact match**。

**既有调用模式（`cli/app.py:213-220`）：**

@topic_app.command(name="browse")
def topic_browse(path: str = typer.Argument(...), workspace: Path = typer.Argument(Path.cwd())) -> None:
    from cpho_cli.core.index import find_problems_by_topic

**REPL 套用 + 分歧（异常不退出 — D-19/D-21）：**
```python
from cpho_cli.core.index import query_index, get_problem_entry, IndexNotFoundError
from cpho_cli.cli.repl import display
from cpho_cli.cli.repl.commands import Command, registry  # 不应有循环 import — 实际在 register() 内 import

async def do_search(session: SessionState, args: list[str]) -> None:
    # 参数解析用 argparse（D-06：内部 argparse；用户面对的 help 来自 Command.help）
    parser = argparse.ArgumentParser(prog="/search", add_help=False)
    parser.add_argument("tag")
    parser.add_argument("--limit", type=int, default=session.max_results)
    try:
        ns = parser.parse_args(args)
    except SystemExit:
        display.error("/search 参数错误，输入 /help search 查看用法")
        return

    try:
        entries = query_index(session.workspace_path, physics_model_ids=[ns.tag])
    except IndexNotFoundError:
        # D-19: 明确报错，不自动 build
        display.error("未找到索引，请先运行: cpho index --workspace " + str(session.workspace_path))
        return

    # 更新 session — 只存 ID（D-11/D-24）
    session.last_search_query = ns.tag
    session.last_search_result_ids = [e.problem_id for e in entries[:ns.limit]]

    # 渲染表格
    rows = [[e.problem_id, "...", ",".join(r.internal_id for r in e.physics_model_tags), str(e.problem_path.name)] for e in entries[:ns.limit]]
    print(display.render_table(["ID", "摘要", "标签", "来源"], rows))

def register(registry: dict[str, Command]) -> None:
    registry["/search"] = Command(
        name="/search",
        help="按标签搜索题目",
        usage="/search <tag> [--limit N]",
        handler=do_search,
        category="搜索",
    )
    registry["/show"] = Command(name="/show", help="...", usage="/show <problem_id> [--full]", handler=do_show, category="搜索")
```

**`/show` 数据流（D-11 + D-13）：**
- 调 `get_problem_entry(session.workspace_path, problem_id)` 拿到 `IndexEntry`
- compact: 取 `entry` 字段直接渲染（前若干字符 + tags + 来源 + page）
- full: 读 `entry.ocr_cache_path`，传给 `display.pager(text)`

### Atomic file write (来源 `core/index/storage.py:13-19`)

### Exception 层次（来源 `core/index/__init__.py:1-17`）
**应用于：** REPL 不引入新异常类。所有 REPL 错误处理 catch core 已定义的 `IndexNotFoundError`, `IndexBuildError`, `ConfigError`, `VocabularyError`, `ProblemNotIndexedError`。

```python

```

### Re-export 风格（来源 `core/index/__init__.py:22-103`）
**应用于：** `cli/repl/__init__.py`、`cli/repl/commands/__init__.py`。
注释标记 `# --- ... ---` 分组 re-export；`__all__` 显式列出。

### Pydantic StrictModel vs dataclass 二分（来源 `models/config.py:7` + `core/index/storage.py:33`）
- **运行时可变状态** → `@dataclass`：`SessionState`, `Command`
- **解析/校验/不可变值对象** → `StrictModel` (Pydantic)：`IndexMeta`
- **冻结的内部数据结构** → `@dataclass(frozen=True)`：N/A（REPL 无此场景）

### 中文 UX（来源 `cli/app.py:88-97, 154-183`）
**应用于：** 所有 user-facing 字符串、help、usage、error 消息。
范例：`"扫描题目数:"`, `"完成. 索引:"`, `"未找到索引，请先运行 cpho index"`。
**新代码必须遵守** —— PROJECT.md 约束 + AGENTS.md §3「匹配现有风格」。
