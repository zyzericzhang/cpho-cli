  <action>
    Implement `ReplApp` as a small object, not a `cmd2.Cmd` subclass:
    - Constructor resolves workspace priority: explicit `workspace` > persisted `last_workspace`/session payload > `Path.cwd()`.
    - Loads config, initializes `SessionState`, loads `index_meta`, creates a per-instance copy of global registry, and calls `install_builtin_commands(self.registry)`.
    - Builds `PromptSession(history=FileHistory(history_path()), completer=CphoCompleter(...), lexer=CphoLexer(), style=...)`.
    - `async def run(self) -> None` prints `display.banner`, loops on `prompt_async("cpho> ")`, handles Ctrl+D as exit, Ctrl+C as interrupted command, empty input as no-op, and malformed `shlex.split` as Chinese error.
    - Dispatch uses `registry.get(cmd_name)` and `await cmd.handler(self.session, args)`.
    - Handler exceptions are caught, logged to `~/.cache/cpho/repl.log`, displayed with `display.error`, and the loop continues.
    - `async def run_repl(*, workspace: Path | None, config_path: Path | None, provider_name: str | None) -> None` constructs `ReplApp` and awaits `run()`.
    - On clean exit, call `write_session(session)`; failures are shown but do not convert exit into a crash.

    Tests inject a fake prompt session or pipe input so `/help\n\x04` exits cleanly, unknown commands do not exit, handler exceptions are contained, and importing `cpho_cli.cli.app` still does not import prompt_toolkit.
  </action>
