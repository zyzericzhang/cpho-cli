# 04-03 Plan: Composition YAML Schema and Selection

## Objective

Create strict composition YAML models and deterministic slot resolution for explicit ids, pass slots, and auto spec slots.

## Tasks

1. Add `CompositionFile`, `CompositionSlot`, and `SlotSpec` StrictModel classes.
   - Verify: valid three-way slot schema loads; invalid mixed slots fail.
2. Add load/write helpers for `.cpho/compositions/<name>.yml` and template generation.
   - Verify: stub template has N slots and is valid YAML.
3. Add `resolve_composition_slots(workspace, composition, last_related=None)` using seeded index entries.
   - Verify: explicit id, pass, topic/tag spec, no duplicate problem ids, and no-match error.

## Acceptance

- YAML parsing errors are user-readable.
- Auto selection uses existing `compose_problem_list()` and avoids duplicates.
- `last_related` is only consumed when the caller explicitly requests it.
