## v1 Requirements (Final Status)

### 核心管线 (Core)

- [x] **CORE-01**: 用户可通过默认 `config.local.yml`、显式 `--config` 或环境变量设置 LLM API key — ✓ Validated Phase 1
- [x] **CORE-02**: 用户可指定本地文件夹作为工作空间，通过 Phase 02.1 切分器将多题试卷拆分为独立题目条目 — ✓ Validated Phase 02.1
- [x] **CORE-03**: 用户可通过抽象 OCR 接口提取 PDF/图片文本（含中文+LaTeX） — ✓ Validated Phase 1
- [x] **CORE-04**: 用户可运行 `cpho solve <题目>` 通过 DAG 管线引擎分步执行 LLM 调用 — ✓ Validated Phase 1
- [~] **CORE-05**: 项目包含 20-30 道精选物理竞赛题的黄金测试集 — ⚠ Deferred (eval/golden_tests removed in Phase 02.3; real problem fixture set never populated; carry to v1.1 or user-supplied)

### 索引层 (Index)

- [x] **IDX-01**: 用户运行 `cpho index` 自动生成标签，存入 JSONL 索引文件 — ✓ Validated Phase 2
- [x] **IDX-02**: 索引系统使用内容哈希检测试卷文件变更，仅对变更文件重新索引 — ✓ Validated Phase 2
- [x] **IDX-03**: 后续 skill 通过标签索引检索题目，标签使用受控词汇表 — ✓ Validated Phase 2

### TUI REPL 界面

- [x] **TUI-01**: 用户运行 `cpho repl` 进入 REPL，`/` 斜杠命令支持 Tab 自动补全 — ✓ Validated Phase 02.2
- [x] **TUI-02**: REPL 会话内搜索结果、当前题目等上下文跨命令共享 — ✓ Validated Phase 02.2
- [x] **TUI-03**: Skill 注册为 Command 对象 + 补全规则，新增 skill 不需要修改 REPL 主循环 — ✓ Validated Phase 02.2
- [x] **TUI-04**: 首批实现 `/search` 和 `/show` 两个斜杠命令 — ✓ Validated Phase 02.2

### 内置核心讲解 Skills (Phase 3)

- [x] **SKILL-SOLVE-REPOSITION**: Solve 不返回新解法，对标准答案做逐步审查，错误写入 index skill-tag 层（含 provenance） — ✓ Validated Phase 3
- [~] **SKILL-EXPLAIN-NEW**: Explain 多 Tone × 分栏目 × 句子级 × 回写 Index — ⚠ Shipped Phase 3 (Tone design); **superseded by v1.1** (2026-05-27 new understanding replaces Tone with 板块 selection, architecture refactor required)
- [x] **SKILL-PROBE**: 主动提问 Skill，连续对话寻找关键点，生成 markdown 文件（前半问题、后半解答） — ✓ Validated Phase 3

### Skill 通用跨切面能力 (Phase 3)

- [x] **CROSS-EXPORT**: 所有 skill 运行结束都可一键导出为 markdown，路径/文件名规则统一 — ✓ Validated Phase 3
- [x] **CROSS-FOLLOWUP**: 所有 skill 结束后用户进入 Follow-up 对话模式 — ✓ Validated Phase 3
- [x] **CROSS-PROGRESS**: 所有 skill 运行过程中有进度显示（当前步/正在做什么/已耗时） — ✓ Validated Phase 3
- [x] **CROSS-ORDER**: Solve 优先于其他 skill 运行——其他 skill 在校正过的标答基础上工作 — ✓ Validated Phase 3

### 知识网络应用 Skills (Phase 4)

- [x] **SKILL-RELATED**: 找同类题 skill，基于 index 标签层返回按相似度排序的同类题列表 — ✓ Validated Phase 4
- [x] **SKILL-COMPOSE**: 编排文件消费 → 从原始 PDF 裁剪拼接题目卷+答案卷（不做 LaTeX 重渲染）；支持自动选题 — ✓ Validated Phase 4

### 异常边界处理 (Phase 4)

- [x] **ROBUST-BOUNDARY**: 外接硬盘拔出/Ctrl+C/文件越界/OCR+LLM 失败都有明确失败提示；中间产物落盘可恢复 — ✓ Validated Phase 4

### 用户手册 + 开源准备 (Phase 5)

- [x] **DOCS-README**: README.md 遵循开源版面；含截图/asciinema；新用户 10 分钟内可运行第一个 skill — ✓ Validated Phase 5
- [x] **DOCS-USER**: `docs/user/` 按 skill/模块分章提供延伸文档 — ✓ Validated Phase 5
- [x] **PLUGIN-PY-SIMPLE**: 简化 Python 扩展机制有专门文档 — ✓ Validated Phase 5

|---------|--------|
| GUI / Web 界面 | v1 纯命令行 + TUI REPL |
| 数据库存储 | 文件系统 + JSONL 足够 |
| 多用户 / 权限 / 登录系统 | 本地单用户工具 |
| LaTeX 渲染引擎 | PDF 输出采用图片拼接方案 |
| 自主 ReAct-style Agent | 确定性 DAG 管线 |

| 跨 skill 自动注入相关题目上下文 | 由用户显式串联 |
