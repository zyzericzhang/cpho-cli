## Overview

CPHO CLI v1.0 delivers a local command-line tool for physics competition coaches and deep learners to run AI-driven analysis on a folder of exam PDFs. The milestone establishes the full core pipeline: multi-problem paper splitting → OCR → tag indexing → REPL interface → explain / probe / solve / related / compose skills → user docs and open-source packaging.

**Key Decisions:**
- DAG pipeline over autonomous agent — deterministic step execution for physics derivation quality
- Three-tier hashing (file/semantic/user-learning) for incremental index updates
- PaperFile/ProblemEntry split model — workspace is paper-centric, index is problem-centric
- Tag provenance model — LLM tags vs skill-written tags stored separately, force-rebuild only clobbers LLM tags
- PDF composition via image stitching, not LaTeX re-rendering
- Simplified Python extension mechanism (user edits code) over YAML skill loader

**Known Gaps at Close:**
- CORE-05: 黄金测试集 (20-30 real physics problems) never populated — deferred to v1.1 or user-supplied
